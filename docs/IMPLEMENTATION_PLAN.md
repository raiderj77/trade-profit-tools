## Phase 3, first paid installation

Only after a deposit:

1. Duplicate the repository or create a customer branch.
2. Replace customer-facing values in `src/config/site.ts`.
3. Replace contact and payment environment variables.
4. Adjust defaults for the agency's main niche.
5. Confirm formulas with the buyer.
6. Deploy to the buyer's domain or provide embed code.
7. Complete one revision.
8. Collect final payment.
9. Request a two-sentence testimonial.

## Phase 4, evidence-based improvements

Only after repeated buyer requests:

- Optional CRM webhook.
- Downloadable PDF result.
- Niche-specific default sets.
- Custom questions.
- Agency analytics event hooks.
- Additional result explanations.

Each addition requires evidence from paid buyers. Do not build a self-service SaaS until manual installs sell repeatedly.
